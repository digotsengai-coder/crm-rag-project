# 使用流程與上手

## 如何開始使用

不需要工程背景，透過後台介面操作即可完成設定，最快 5 分鐘就能上線第一台客服機器人。
大致流程如下：

1. **註冊帳號**：使用 Google 登入即可建立帳號。
2. **建立機器人並上傳資料**：在後台上傳商品資料或知識庫文件，讓機器人可以依真實資料回答問題。
3. **設定回答模型**：選擇要使用的 LLM 供應商（可依需求切換）。
4. **選擇部署通路**：把機器人嵌入官網、串接 LINE 官方帳號，或串接 Facebook 粉專。
5. **上線測試**：透過後台預覽功能直接測試機器人的回答效果，確認無誤後正式對外提供服務。

## 如何上傳知識庫文件

後台支援上傳 PDF、Word 等常見文件格式，系統會自動將文件內容切分成適合檢索的片段
（chunk），建立 RAG 索引後，機器人就能依這些內容回答客人的問題。建議上傳前先確認
文件內容正確、避免過時資訊，才能提高回答準確度。

## 如何設定訂單系統串接

若商家希望機器人能查詢真實訂單狀態，可以透過 MCP 工具設定串接：

1. 在後台的機器人設定頁面產生 MCP Token。
2. 將 Token 提供給自己的訂單系統或串接服務使用。
3. 串接完成後，客人在對話中問「訂單到哪了」，機器人就能直接查詢並回覆真實出貨進度。

## 如何嵌入官網 / LINE / Facebook

- **官網嵌入**：在後台取得嵌入程式碼，貼到官網頁面即可顯示聊天視窗。
- **LINE**：在後台設定 LINE 官方帳號的串接資訊，完成綁定後客人就能透過 LINE
  與機器人對話。
- **Facebook**：在後台設定 Facebook 粉專的串接資訊，完成綁定後客人可透過粉專私訊
  與機器人對話。

所有通路的對話紀錄都會統一顯示在同一個後台，方便商家集中管理。
