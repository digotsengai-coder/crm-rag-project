# 適用情境與導入效益

## 適合哪些商家

- **電商 / 網路商店**：客人常問商品是否有現貨、規格、什麼時候會到貨、訂單出貨進度，
  機器人可以直接依商品資料與知識庫回答，並串接訂單系統查詢真實出貨狀態。
- **零售門市**：可將常見的商品諮詢、營業時間、門市資訊等整理成知識庫，
  讓機器人在官網或 LINE 上隨時回覆客人。
- **服務業**：可將服務項目、預約流程、常見問題整理成知識庫，
  減少客服人員重複回答相同問題的負擔。

不論商家規模大小，只要有商品問答或訂單查詢需求、且客服人力有限，
都適合導入這套系統。

## 導入後可以節省什麼

- **減少重複對話**：商品規格、庫存、出貨進度等重複性高的問題，
  由機器人 24 小時全天候即時回覆，平均 1~3 秒回覆速度，不需要客人等待人工客服上線。
- **降低客服人力負擔**：客服團隊可以把時間集中在需要人工處理的複雜問題上，
  機器人先接住大部分的重複對話。
- **多通路集中管理**：官網、LINE、Facebook 三個渠道的對話紀錄統一在同一個後台管理，
  不需要分別在不同平台切換查看。
- **回答品質可被檢視**：透過稽核紀錄與每日摘要，商家可以掌握機器人的回答狀況，
  持續優化知識庫內容。

## 常見使用情境範例

- 客人問「這個有現貨嗎？大概什麼時候會到？」——機器人依商品資料回覆現貨狀況與
  預計出貨時間。
- 客人問「幫我查一下我的訂單」——機器人透過訂單系統串接查詢真實狀態，
  回覆訂單編號、出貨與預計送達時間。
- 客人在 LINE 或 Facebook 私訊詢問問題——機器人在對應通路即時回覆，
  對話紀錄同步顯示在後台。
